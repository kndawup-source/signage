[TV 연결 코드 (설치형 플레이어)]
- 상태: 발급(issued) → 승인(approved) → 인증 정보 전달(delivered) → 기기 저장 확인(confirmed)
- 코드 유효시간 10분. 승인하면 그 시점부터 10분 연장. 만료된 코드는 승인 여부와 상관없이 사용 불가.
- 승인할 때마다(첫 연결 포함) 인증 키를 새로 만들고, 승인된 기기 1대만 그 키를 받을 수 있습니다.
  저장 확인 전 네트워크가 끊기면 같은 기기만 재수신 가능. 승인 후 해제·교체되면 전달하지 않습니다.
- 병원별 오입력 10분 10회 초과 시 10분 잠금 (다른 병원에는 영향 없음).
- 이미 연결된 TV에 새 코드를 입력하면 "교체 확인" 후 승인. "기존 기기 연결 해제"도 확인창 후 실행.
  교체·해제된 이전 키(기존 설치형 기기·기존 TV 연결 주소)는 영상 수신·상태 보고가 즉시 불가하고,
  해당 플레이어는 서버에 닿는 즉시 송출을 멈춥니다. 해제된 TV는 '미연결'로 표시됩니다.
- 첫 연결에도 키가 바뀌므로, 같은 TV에 예전에 복사해 둔 웹 연결 주소는 더 이상 쓸 수 없습니다.

[TV 상태 5분류]
정상 송출 / 대기 중(운영시간 외·일시정지) / 미연결(설치 전) / 확인 필요(꺼짐·오류·지연) / 직접 관리
- 운영시간 외, 일시정지, 설치 전 TV는 장애(확인 필요)에 포함되지 않습니다.
- 대시보드·층별 화면·TV 상세·상태 필터가 같은 판정(js/common.js Signage.tvStatus)을 씁니다.
